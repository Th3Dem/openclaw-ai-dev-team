Least Privilege Security Architecture

Traditional AI coding setups suffer from catastrophic hallucinated commits and permission leaks. OpenClaw enforces hardware-isolated roles where developers cannot touch git remotes, QA cannot alter code, and only the dedicated release guardian merges verified pull requests.

DEV ISOLATION Dev bots write code and unit tests only. No write access to git remote or prod environments.
INDEPENDENT AUDIT QA bot acts as an unbypassable gatekeeper before any code can be considered complete.
IMMUTABLE AUDIT TRAIL Every single action, decision, test output, and handoff is logged append-only in WORKLOG.md.
